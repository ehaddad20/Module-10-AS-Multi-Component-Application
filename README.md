# Module 10 State Management

A Student Portal Dashboard built with React and TypeScript. It shows how to share state between components without passing props down.

## What it uses
- Context API and useContext for the user (UserContext) and the theme (ThemeContext)
- A custom hook, useGreeting
- A Zustand store for notifications
- Zustand persist middleware, so notifications are saved in local storage and stay after a refresh

## What you can do
- See the logged in user
- Toggle dark mode
- See the notification count
- Add and clear notifications
- Refresh the page and keep your notifications

## How to run
```
npm install
npm run dev
```
